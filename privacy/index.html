Privacy Policy

Last updated: 9 November 2026

This policy covers the website make.pictures and the internal tool make.pictures stats (a Google OAuth application). Both are operated by Paweł Bart. Contact: hello@make.pictures.

Website visitors

The website uses Umami Cloud for privacy-friendly, cookieless analytics. Umami collects aggregated, anonymous data (page views, referrer, country, browser and device type). It does not use cookies and does not collect personal data that identifies you. The website has no user accounts and no forms.

make.pictures stats (Google OAuth application)

make.pictures stats is a private, self-hosted tool used solely by the owner of the make.pictures YouTube channels to view statistics for their own channels. It is not offered to the public.

  • Data accessed: read-only access via the scopes youtube.readonly and yt-analytics.readonly — channel and video metadata and aggregated YouTube Analytics reports (views, watch time, audience retention, traffic sources, subscribers gained/lost).
  • How it is used: only to display statistics in a local dashboard on the owner's computer.
  • Storage: OAuth refresh tokens and statistics snapshots are stored only locally on the owner's computer. No data is stored on any server operated by make.pictures.
  • Sharing: data is not sold, shared with or transferred to third parties, and is not used for advertising or for training AI/ML models.
  • Revoking access: access can be revoked at any time at myaccount.google.com/permissions.

make.pictures stats' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see also the YouTube Terms of Service and the Google Privacy Policy.

make.pictures stats (aplikacja Google OAuth)

make.pictures stats to prywatne narzędzie uruchamiane lokalnie, używane wyłącznie przez właściciela kanałów YouTube make.pictures do podglądu statystyk własnych kanałów. Nie jest udostępniane publicznie.

  • Zakres danych: dostęp tylko do odczytu (youtube.readonly, yt-analytics.readonly) — metadane kanału i filmów oraz zagregowane raporty YouTube Analytics (wyświetlenia, czas oglądania, retencja, źródła ruchu, subskrypcje).
  • Cel: wyłącznie wyświetlanie statystyk w lokalnym dashboardzie.
  • Przechowywanie: tokeny OAuth i migawki statystyk są zapisywane tylko lokalnie na komputerze właściciela; make.pictures nie przechowuje ich na żadnym serwerze.
  • Udostępnianie: dane nie są sprzedawane ani przekazywane osobom trzecim, nie są używane do reklam ani do trenowania modeli AI/ML.
  • Cofnięcie dostępu: w dowolnym momencie na myaccount.google.com/permissions.

Wykorzystanie i przekazywanie informacji otrzymanych z interfejsów API Google jest zgodne z Google API Services User Data Policy, w tym z wymaganiami Limited Use.
